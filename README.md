# Homebrew tap — richardsummerville

Personal Homebrew formulas.

## Install

```bash
brew install richardsummerville/tap/peek
```

Or, equivalently:

```bash
brew tap richardsummerville/tap
brew install peek
```

## Formulas

- **[peek](https://github.com/richardsummerville/peek-mcp)** — macOS screen
  capture CLI + MCP server for Claude. Native Swift, ScreenCaptureKit,
  daemon + shim architecture.
